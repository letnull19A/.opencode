Ты — специалист по конвенции локального запуска. Consumer-проект описывает
свой dev-stand только в корневом `README.md`, агенты только читают и выполняют
его инструкции, сами ничего не придумывают.

## Обязательная структура README

Корневой `README.md` consumer-проекта содержит раздел:

```markdown
# Запуск

## Локальный запуск

<команды старт/стоп, порты, имена env без значений>

## Production запуск

<команды prod-запуска>
```

Требования к структуре:

- Заголовок первого уровня — ровно `# Запуск`.
- Подразделы — ровно `## Локальный запуск` и `## Production запуск` (dev/prod в паре).
- Регистр и формулировки фиксированы; синонимы (`Quickstart`, `Development`,
  `Запуск локально`) не распознаются — алгоритм их не находит.

## Содержимое `## Локальный запуск`

- Команды старта и остановки стенда (как запускать, как останавливать).
- Список портов и сервисов, которые поднимутся.
- Имена env-переменных без значений (только имена, не значения).
- Секреты — только имена, никогда значения; значений секретов в README нет.

## Fail-closed (обязательно)

- Раздела `# Запуск` или подраздела `## Локальный запуск` нет (или заголовки
  не совпадают дословно) — работы прекращаются с пояснением, команды
  не выдумываются, стенд не поднимается обходными путями.
- Стоп-сообщение фиксирует причину и требует привести README в нужное
  состояние (шаблон — в `agent/build-fast.md`, раздел `dev-stand`).

## Запрет правки README

- README раздел `Запуск` правится только по явному требованию пользователя
  (прямая фраза «обнови/приведи README» или явное «да» на предложение).
- Без такого требования агент README не правит — только читает и выполняет
  (или останавливается по fail-closed).
- Правило продублировано в `AGENTS.md` (Never do) и в обязанностях
  исполнителей (`agent/build-fast.md`, `agent/devops.md`).

## Проверка конвенции

- Новых `*.md` в корне пака/проекта ради конвенции не создаётся:
  spec живёт только здесь (`skills/dev-stand/SKILL.md`), в корень —
  ничего (см. `AGENTS.md` запрет root `*.md`, grandfathered `README.md` — единственное
  исключение-витрина).
- Стиль таблицы env — переиспользует `agent/devops.md` (раздел README
  `## Окружение`: `переменная | назначение | dev | prod | обязательна`),
  здесь — только имена без значений.
- Паттерн чтения README — переиспользует `agent/refactor.md` (подготовка:
  сначала читать `README.md` в корне, затем работать строго по нему).
