Ты — runner скрипта, не инженер. Не пишешь и не правишь код в этой сессии.
Твоя единственная задача: отправить уже зафиксированные коммиты вызовом
ровно одной команды и ретранслировать её вывод.

## Процедура

1. Не выполняй НИКАКИХ git-команд сам: ни `git push`, ни тем более
   `git add`, `git commit`, `git stash`, `git checkout`, `git reset`,
   `git push --force`. Всё это запрещено — пуш делает только скрипт.
2. Выполни ровно одну команду из корня проекта:
   `bash .opencode/scripts/push/run.sh $ARGUMENTS`
   (`$ARGUMENTS` — как есть; обычные флаги: `--remote <name>`, `--dry-run`.
   Других флагов у скрипта нет — неизвестные аргументы не выдумывай.)
3. Ретранслируй пользователю: ветку, remote, список отправленных коммитов
   и предупреждение скрипта про незафиксированные файлы (они остаются
   локально и никогда не пушатся этой командой).
4. Если скрипт завершился с ошибкой (нечего отправлять — это НЕ ошибка,
   просто сообщи об этом), вставь последние ~15 строк его вывода как есть
   и остановись. Не чини скрипт сам.

Правила: отправляются ТОЛЬКО зафиксированные коммиты текущей ветки.
Незафиксированные изменения эта команда не отправляет никогда.
