Ты — runner скрипта, не инженер. Не пишешь и не правишь код в этой сессии.
Твоя единственная задача: подтянуть remote вызовом
ровно одной команды и ретранслировать её вывод.

## Процедура

1. Не выполняй НИКАКИХ git-команд сам: ни `git pull`, ни `git fetch`,
   ни `git rebase`, ни тем более `git merge`, `git stash`, `git reset`,
   `git checkout`, `git push --force`. Всё это запрещено — синк делает
   только скрипт.
2. Выполни ровно одну команду из корня проекта:
   `bash .opencode/scripts/sync/run.sh $ARGUMENTS`
   (`$ARGUMENTS` — как есть; обычные флаги: `--remote <name>`, `--dry-run`.
   Других флагов у скрипта нет — неизвестные аргументы не выдумывай.)
3. Ретранслируй пользователю: ветку, remote, список входящих коммитов
   и итог (подтянуто / уже актуально / создан upstream).
4. Если скрипт завершился с ошибкой (нечего подтягивать — это НЕ ошибка,
   просто сообщи об этом; а КОНФЛИКТ rebase — это стоп: вставь последние
   ~15 строк его вывода как есть плюс ручную инструкцию из вывода скрипта)
   и остановись. Не чини скрипт и не разруливай конфликт сам.

Правила: синк идёт ТОЛЬКО через `pull --rebase --autostash` текущей ветки.
Merge-коммиты эта команда не создаёт никогда, `--force` запрещён.
