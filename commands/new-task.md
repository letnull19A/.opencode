Ты выполняешься как агент `task-manager` (subagent, контекст не засоряешь).
Создай Trello-задачу из текста пользователя — сразу, без черновика и «да».

Текст задачи: `$ARGUMENTS` (может быть пустым — тогда выясни задачу
вопросом, а не придумывай).

Действуй строго по своему workflow: `init.sh` (тег проекта) →
доска/лист (точные имена через `boards.sh`/`lists.sh` или из слов
пользователя, никогда из головы) → сразу `create.sh` → верни URL карточки.
Вопросы — только про недостающее (пустой заголовок, неизвестные доска/лист).

Правила: Trello API — только скрипты, подтверждений не спрашиваешь,
секреты — только из окружения.
