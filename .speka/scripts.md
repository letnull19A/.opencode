# Название

Словесное описание групп скриптов пакета.

# Назначение

Перечислить все группы скриптов как единственных исполнителей мутаций и проверок, чтобы агенты знали, что думать им, а исполнять скриптам.

# Входы

- Каталог групп скриптов и их описания
- Связи скриптов с навыками и инструментами

# Выходы

- Перечень групп скриптов с ролью каждой словами
- Понимание, какой скрипт за какую операцию отвечает

# Зависимости

- Навыки, задающие дисциплину вызова
- Инструменты, являющиеся обертками над скриптами

# Ограничения

- Только слова, без программных блоков и без команд для копирования
- Без секретных значений
- Скрипты исполняют, агенты не дублируют их логику вручную

# Когда использовать

- Когда нужно понять, каким скриптом выполнить операцию
- Когда нужно проверить, что операция идет через скрипт, а не вручную

# Перечень групп словами

Веточные операции: проверка изоляции, движение только вперед и финиш через завершение.

Цепочки шагов: последовательное выполнение связанных шагов.

Проверки изменений: типы, стиль, формат и проверки окружения только по различиям.

Непрерывная интеграция: скаффолд конвейеров из шаблонов и проверка статусов чтением.

Связь коммитов и задач: поиск связи коммитов с карточками по трейлерам в сообщениях.

Доставка коммитов: отправка только зафиксированного без добавления и форсирования.

Дизайн: создание руководства из шаблона, программная выдача контекста правил и предкоммитная проверка.

Упаковка образов: скаффолд послойной упаковки и игнорируемых файлов из шаблонов.

Диагностика окружения: сводная проверка состояния.

Развертывание: управление проектами, приложениями и доменами на платформе развертывания.

История изменений: сводка грязного дерева и свежих коммитов с трейлерами задач.

Разведка репозитория: чтение состояния одиночными командами.

Индекс файлов: построение графа зависимостей файлов для оценки сложности.

Автор проблем: проверка структуры, предпросмотр и создание обращений через внешнего провайдера.

Планировщик батчей: подбор легких задач группой и проверка наличия инструкции.

Порты: управление занятыми портами окружения.

Запросы слияния: создание по схеме с проверкой, чтение ссылки, сверка статуса, обновление и список.

Проверка подсказок: контроль качества текстов подсказок.

Отправка: детерминированная отправка зафиксированного.

Поиск классов: поиск стилевого класса в разметке и стилях с табличным выводом для агента.

Отчеты по снимкам: захват страниц, построение отчета и отправка выбранным способом.

Безопасность: контроль staged-ввода на опасные приемники и непроверенный ввод.

Синхронизация: подтягивание через перебазирование с автосохранением.

Коммиты задач: связь коммитов с карточками.

Управление задачами: инициализация профиля, миграция наследия, списки досок и листов, создание и перемещение карточек, чек-листы, комментарии, аудит.

Тоннели предпросмотра: запуск, статус, перезапуск и остановка внешнего доступа.

Рабочие копии: создание, список, статус, удаление и завершение жизненного цикла.
