# Название

Словесное описание пользовательских команд пакета.

# Назначение

Перечислить все команды как тонкие оболочки над скриптами и подагентами, чтобы пользователь знал, какая команда какую операцию запускает.

# Входы

- Файлы команд и их назначение
- Связанные скрипты и агенты

# Выходы

- Перечень команд с ролью каждой словами
- Понимание, где команда думает, а где только запускает

# Зависимости

- Скрипты отправки, синхронизации, задач и запросов слияния
- Подагенты задач, исправлений и модулей

# Ограничения

- Только слова, без программных блоков
- Без секретных значений
- Слияние запросов принимает только человек, агент слияние не выполняет

# Когда использовать

- Когда нужно отправить, синхронизировать, зафиксировать или попросить задачу
- Когда нужно исправить интерфейс, создать модуль, проверить диагностику или запрос слияния

# Перечень команд словами

Вопрос: ответ через чтение без изменений.

Цепочка: запуск связанной последовательности шагов.

Коммит: разбор различий и создание атомарных сообщений без отправки.

Диагностика: расследование сбоя с отчетом о виновнике.

Эволюционный план: подготовка плана под карточки задач.

Исправление: делегирование точечному исправителю интерфейса.

Новый модуль: запуск жизненного цикла модуля через стратегию добавления или изменения.

Новая задача: делегирование ответственному за задачи.

Запрос слияния: создание, обновление и список через скрипты с обязательной кликабельной ссылкой; принятие только человеком.

Отправка: отправка только зафиксированного без добавления и форсирования.

Синхронизация: подтягивание только через перебазирование с автосохранением.
