# Название

Словесное описание контрольных проверок качества и безопасности.

# Назначение

Перечислить все гейты, которые обязаны пройти изменения до фиксации и завершения, и объяснить строгость каждого.

# Входы

- Незафиксированные изменения как предмет проверки
- Руководство по стилю, правила безопасности и контракт качества

# Выходы

- Решение пропустить, предупредить или остановить словами
- Перечень замечаний для исполнителя

# Зависимости

- Скрипты проверок, безопасности и стиля
- Гейт качества кода перед завершением
- Человек как утверждающий при блокирующих нарушениях

# Ограничения

- Только слова, без программных блоков
- Без секретных значений
- Блокирующие нарушения требуют явного утверждения человеком, без него фиксации нет
- Проверяются только изменения, а не все дерево

# Когда использовать

- Перед добавлением в индекс и перед каждым коммитом
- Перед завершением задачи исполнителем
- При споре о стиле или безопасности

# Перечень гейтов словами

Проверка различий: типы, стиль, формат и ворота окружения только по измененному.

Безопасность ввода и вывода: вход проверяется на границе по схемам, выход сериализуется через схемы, запрещены опасные приемники и сборка запросов склеиванием строк; опасное — остановка, остальное — предупреждения с предложением правок проверок.

Стиль интерфейса: руководство как источник правды через программный контекст; запрещенные приемы останавливают, мелкие замечания не блокируют; правки руководства вносит только владелец по точному предложению.

Качество кода: сверка с правилами и контрактом по фиксированным критериям задачи, контрактов, принципов, статики, безопасности, тестов, читаемости и гигиены области; код не правит, возвращает вердикт одобрено, нужна доработка или пропущено при пустых изменениях.

Присутствие ключа внешней классификации: без ключа используется локальная эвристика с предупреждением о настройке, которое обязательно передается дальше.

Пороги гейтов словами: проверка различий только по измененному; скаффолд проверяется построчным разбором и запретом удаления дерева и форсирования и поиском вложенных значений окружения; сухой прогон блокирует мутации; лимиты чтений от одного до двадцати восьми и записей от одной до восьми соблюдаются на каждом шаге.
