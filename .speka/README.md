# Название

Индекс описаний пакета и единый стандарт секций для каталога описаний.

# Назначение

Дать единую точку входа в словесные описания пакета: что где лежит, как читать остальные файлы каталога, и какой стандарт секций они соблюдают. Сам каталог только описывает словами, ничего не исполняет и исходный пакет не меняет.

# Входы

- Структура каталогов пакета: агенты, навыки, скрипты, инструменты, рабочие процессы, команды, плагины, конфигурация
- Описания назначений, прочитанные из заголовочных полей исходных файлов
- Требование единообразия структуры всех файлов описаний

# Выходы

- Перечень файлов описаний с указанием, за какую категорию каждый отвечает
- Определение стандарта из семи секций, обязательного для каждого файла
- Понимание границ: только слова, без исполняемых фрагментов и секретных значений

# Зависимости

- Остальные файлы данного каталога описаний, раскрывающие каждую категорию детально
- Исходные каталоги пакета как предмет описания, без их изменения

# Ограничения

- Только словесное описание, без программных блоков и без команд для копирования
- Без секретных значений, ключей и токенов
- Без правок исходного пакета, только добавление описаний
- Гранулярность описаний задается словами ниже в разделе индекса, а не кодом

# Когда использовать

- Когда нужно понять состав пакета перед чтением деталей
- Когда нужно проверить, что новый файл описания следует общему стандарту
- Когда нужно найти, в каком файле описана нужная категория

# Индекс файлов и стандарт секций

Стандарт: каждый файл описаний содержит ровно семь разделов в фиксированном порядке: Название, Назначение, Входы, Выходы, Зависимости, Ограничения, Когда использовать. Дополнительно файл может иметь один поясняющий раздел после них, но семь базовых обязательны и идут первыми.

Состав каталога из двенадцати файлов:

- README — данный файл, индекс и стандарт
- agents — словесное описание всех агентов по отделам
- skills — словесное описание всех навыков
- scripts — словесное описание всех групп скриптов
- tools — словесное описание всех инструментов
- workflows — словесное описание всех рабочих процессов
- commands — словесное описание всех пользовательских команд
- plugins — словесное описание регистрации инструментов через плагин
- config — словесное описание конфигурации, дисциплины прав и профиля проекта
- pipelines — словесное описание сквозных конвейеров работы
- guards — словесное описание контрольных проверок качества и безопасности
- glossary — словесное описание ключевых терминов пакета

Гранулярность словами: уровень агентов — по одному пункту на каждого агента, сгруппированного по отделам; уровень навыков — по одному пункту на каждый навык; уровень скриптов — по одному пункту на каждую группу скриптов; уровень инструментов — группировка по назначению (классификаторы, задачи, инфраструктура, проверки); уровень процессов — по одному пункту на каждый процесс; уровень команд — по одному пункту на каждую команду; уровень плагинов — по одному пункту на каждый программный модуль плагина; уровень конфигурации — по одному пункту на каждый конфигурационный файл и свод правил.
