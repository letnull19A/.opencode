# Название

Словесное описание сквозных конвейеров работы.

# Назначение

Показать типовые связки думать, исполнять, проверять и доставлять как единый порядок, чтобы исполнитель не пропускал гейты.

# Входы

- Запрос пользователя или карточка задачи
- Выбранный рабочий процесс и классификаторы

# Выходы

- Готовый результат с проверками и отчетом словами
- Понимание, кто отвечает за каждый этап

# Зависимости

- Агенты разведки, планирования, исполнения и проверки
- Скрипты задач, проверок, безопасности, дизайна, отправки и запросов слияния

# Ограничения

- Только слова, без программных блоков
- Без секретных значений
- Движение только вперед по истории, без слияний и форсирования
- Тесты первичны: код приводится к тестам, а не наоборот

# Когда использовать

- Когда новая задача идет от фразы до карточки и реализации
- Когда интерфейс требует стиля, проверки и отчета
- Когда изменения готовятся к фиксации и отправке

# Конвейеры словами

От фразы до карточки: проверка структуры, классификация, разведка повторного использования, план, создание с предпросмотром.

От карточки до кода: выбор быстрого, умного или инфраструктурного исполнителя либо исполнителя по умолчанию, работа строго по плану, верификация реальным запускником.

Интерфейсный: контекст правил программно, работа строго по руководству, предкоммитная проверка стиля, обновление разделов и журнала владельцем.

Фиксация и доставка: атомарные сообщения группами по смыслам, проверка staged-ввода, проверка стиля для интерфейса, отправка только зафиксированного, ссылка на запрос слияния после операций, принятие только человеком.

Диагностический: разведка состояния, пошаговое следствие, отчет о виновнике.

Пороги словами: разбиение стартует выше ста строк к цели двадцать пятьдесят не более трех циклов; поиск дублей порог шестьдесят пять сотых; создание карточек не более трех при не более пяти записей; сухой прогон обязателен перед мутациями.
