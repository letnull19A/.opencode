# Название

Словесное описание рабочих процессов пакета.

# Назначение

Перечислить все рабочие процессы как готовые сценарии из шагов с ограничениями, чтобы маршрутизатор выбирал сценарий, а не импровизировал.

# Входы

- Декларации процессов и их шаги
- Движок выполнения и файл общих ограничений

# Выходы

- Перечень процессов с назначением и шагами словами
- Понимание триггеров запуска каждого процесса

# Зависимости

- Инструменты, разрешенные на каждом шаге
- Навыки маршрутизации, вложенности и планирования

# Ограничения

- Только слова, без программных блоков
- Без секретных значений
- Шаги соблюдают лимиты чтений и записей и запрет правок там, где чтение только

# Когда использовать

- Когда поступает сырой запрос новой задачи
- Когда нужен сценарий непрерывной интеграции
- Когда нужно разбить крупную задачу или интерфейс на части

# Перечень процессов словами

Новая задача: путь от сырой фразы до готовой карточки через проверку структуры, классификацию подхода, классификацию доступа, разведку повторного использования, компиляцию плана и создание с предпросмотром без мутаций. Сложный план дополнительно компилирует матрицу из четырех факторов и связи блокировок.

Непрерывная интеграция скриптом: путь от опроса требований через цель, классификацию, план, скаффолд и проверку до отчета, способом через переносимые команды оболочки для исполнителя инфраструктуры.

Разбиение: разделение крупной единицы на мелкие части с порядком и связями.

Интерфейс: двухэтапное проектирование через абстрактный концепт, затем архитектуру дерева и контрактов, затем реализацию.

Лимиты шагов словами: новая задача проверка не более одного чтения без инструментов правки; классификация не более двух чтений через планировочный классификатор; классификация доступа не более четырех чтений без правок; разведка не более шести чтений через разведку без правок; план не более шести чтений через план; создание не более пяти записей и не более трех карточек. Интерфейс концепт и реализация по не более двух чтений без правок. Непрерывный скриптом опрос не более десяти чтений, цель не более четырнадцати, классификация не более шестнадцати, план не более двадцати, скаффолд не более двух записей, проверка не более двадцати шести чтений, отчет не более двадцати восьми чтений, скаффолд запрещает удаление дерева и форсирование. Разбиение порог сто строк к цели двадцать пятьдесят, не более трех циклов, предкоммит одна запись, копия одна запись, план не более шести чтений, реализация не более восьми записей, проверка не более трех чтений, решение не более двух записей.
