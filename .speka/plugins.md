# Название

Словесное описание плагина регистрации инструментов.

# Назначение

Объяснить, как определения инструментов превращаются в доступный модели каталог через единственную точку регистрации.

# Входы

- Определения инструментов в виде описания, схемы входа и функции исполнения
- Контекст вызова с рабочей копией и каталогом

# Выходы

- Зарегистрированный каталог инструментов словами
- Понимание правила именования и проверки готовности

# Зависимости

- Файлы определений инструментов
- Модуль разрешения корня скриптов
- Проверочный скрипт регистрации

# Ограничения

- Только слова, без программных блоков
- Без секретных значений
- Имя инструмента равно имени файла определения, ссылки в правах опираются на эти имена

# Когда использовать

- Когда нужно понять, почему инструмент виден или отсутствует в каталоге
- Когда добавлен новый инструмент и нужна проверка регистрации
- Когда нужно разобраться в разрешении путей скриптов

# Состав словами

Точка регистрации: берет все определения, проверяет, что исполнение является функцией, иначе инструмент в каталог не попадает, затем оборачивает исполнение, чтобы подставить корень репозитория, и регистрирует.

Разрешение путей словами: контекст вызова в актуальной версии каталог не передает, поэтому корень определяет плагин по порядку — явный аргумент инструмента из пары worktree или directory, затем каталог из контекста вызова, затем каталог сессии, затем канонический checkout; сама раскладка живет в модуле подчеркивание резолв, который ищет скрипт сначала в пакете, затем в корне, без тихих запасных вариантов. Оба ключа корня добавлены в схему входа каждого инструмента и вырезаются из аргументов перед вызовом определения.

Проверка: отдельный проверочный модуль подтверждает регистрацию и три способа получить корень — из сессии, из аргумента инструмента и из канонического checkout — без участия модели.
