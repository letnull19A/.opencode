# sync — подтягивание только через rebase

Реализация философии пака: **агент не думает про git, а вызывает один
скрипт**; всё детерминированное — в коде.

```
[remote-ветка]
     │
     ▼
/sync → bash .opencode/scripts/sync/run.sh → git pull --rebase --autostash
        (только rebase, без merge/--force)
```

Команда `/sync` (`.opencode/commands/sync.md`) — тонкий runner:
агенту запрещено выполнять любые git-команды самому
(`pull`, `fetch` + `rebase` вручную, `merge`, `stash`, `--force` и т.д.).
Скрипт `run.sh` умеет только `git pull --rebase --autostash` текущей
ветки, поэтому история не плодит merge-коммиты, а незафиксированные
изменения переживают синк автоматически.

## Файлы

- `.opencode/commands/sync.md` — команда `/sync`, вызывает только `run.sh`.
- `.opencode/scripts/sync/run.sh` — детерминированный синк:
  проверки (git-репозиторий, ветка не detached, remote существует),
  привязка upstream при первом синке, `git fetch` + показ входящих
  коммитов, затем `git pull --rebase --autostash`.
- `opencode.json` — `bash .opencode/scripts/sync/run.sh*` в allowlist,
  чтобы агент не спрашивал подтверждение на каждый синк.

## Поведение

- Уже актуально (`behind 0`) — успех с сообщением, без лишнего pull.
- Нет upstream, но ветка есть на remote — скрипт привязывает
  (`--set-upstream-to`) и синкает. Ветки нет и на remote — успех
  с подсказкой про `/push` (возможно, ветку ещё не отправляли).
- Грязное дерево — не блокер: `--autostash` припрячет изменения
  и вернёт их сам; агент `stash` руками не трогает никогда.
- Локальные коммиты поверх (`ahead N`) — перебазируются наверх,
  merge-коммита не создаётся.
- Конфликт rebase — ненулевой exit, скрипт останавливается и печатает
  ручную инструкцию (`rebase --continue` / `--abort`); агент вставляет
  последние ~15 строк вывода и останавливается, скрипт не чинит.
- `detached HEAD`, нет remote, упал `git pull` — ненулевой exit,
  агент вставляет последние ~15 строк и останавливается.
- Флаги: `--remote <name>` (по умолчанию `origin`), `--dry-run`
  (fetch + показать входящие, ничего не меняя). `--force`, `merge`
  и аналогов нет и не будет — неизвестные аргументы отклоняются.

## Быстрый прогон вручную (без opencode, для проверки скрипта)

```bash
bash .opencode/scripts/sync/run.sh --dry-run
bash .opencode/scripts/sync/run.sh
```
