## 2. Токены

Имена токенов — единственные разрешённые значения в коде. Магические
hex/px в компонентах запрещены, новый токен — сначала сюда, потом в код.

### Цвета

| Токен | Значение | Назначение |
| ----- | -------- | ---------- |
| `bg` | <!-- #FFFFFF --> | фон |
| `text` | <!-- #111111 --> | основной текст |
| `accent` | <!-- #0066FF --> | акцент/ссылки |

### Типографика

| Токен | Значение | Назначение |
| ----- | -------- | ---------- |
| `font-main` | <!-- Inter, system --> | основной шрифт |
| `title` | <!-- 20px / 700 --> | заголовки |
| `body` | <!-- 14px / 400 --> | текст |

## 3. Компоненты (style-guide, не реестр-дамп)

Переиспользуемые ГЛОБАЛЬНЫЕ UI-элементы (`shared/ui`, UI-кит/пакет) — одна
строка на элемент. Локальные page-компоненты (`app/**/components/*`,
page-local) и константы сюда НЕ вносятся — для них `DESIGN.md` задаёт только
стилевые правила (токены/box-shadow/dark/a11y). Новый глобальный компонент —
сначала сюда (имя/платформа/файл), потом код. Дубли одного и того же
блока в двух местах запрещены: выноси в компонент и регистрируй здесь
(только глобальное).

| Компонент | Платформа | Файл | Props / заметки |
| --------- | --------- | ---- | --------------- |
| <!-- Button --> | <!-- web --> | <!-- src/components/Button.tsx --> | <!-- variant, size --> |
