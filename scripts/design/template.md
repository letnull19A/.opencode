## 2. Токены

Имена токенов — единственные разрешённые значения в коде. Магические
hex/px в компонентах запрещены, новый токен — сначала сюда, потом в код.

### Цвета

| Токен | Значение | Назначение |
| ----- | -------- | ---------- |
| `bg` | <!-- #FFFFFF --> | фон |
| `text` | <!-- #111111 --> | основной текст |
| `accent` | <!-- #0066FF --> | акцент/ссылки |

### Типографика
